# Security Policy

## Supported Versions

| Version | Security Updates |
| --- | --- |
| latest (main branch) | yes |
| prior releases | no |

## Reporting a Vulnerability

The security of this project is a priority. If you believe you have found a security vulnerability, please report it responsibly — not in a public issue.

1. Visit the repository's **Security** tab and click **Report a vulnerability** to submit details through GitHub's private channel. Alternatively, email the security team directly.
2. In your report, include:
   - A description of the vulnerability and the potential impact.
   - Steps to reproduce the issue.
   - The affected version or commit.
   - Any suggested remediation.
3. You will receive an acknowledgment within 2 business days. For critical vulnerabilities, a fix or mitigation is targeted within 7 days.

## Security Contacts

- Security team: `@security-team` (GitHub team)
- Lead contact: security@example.org

## What to Expect

After you report a vulnerability:

- The security team acknowledges receipt.
- The finding is investigated and confirmed.
- A fix is developed and tested.
- A coordinated disclosure and release is planned.

## Out of Scope

The following are not in scope for vulnerability reports:

- Missing `SECURITY.md` in a fork.
- Dependency vulnerabilities already detected by Dependabot.
- Issues that require only non-administrator access.
