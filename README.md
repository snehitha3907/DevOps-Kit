# DevOps-Kit
> A working engineer's DevOps reference for Git, Docker, Kubernetes, Terraform, Ansible, Helm, and more.

## Who this is for
A working DevOps engineer's quick-reference: first-contact notes, runnable snippets, and configs for the tools on disk. Use it as a shelf you grab from, not a tutorial site. It deliberately does not try to replace each tool's official docs.

## What's in here
A collection of notes, scripts, snippets, configs, manifests, templates, and notebooks covering cloud, CI/CD, containers, IaC, observability, and security tooling used day-to-day.

## Layout
- `AWS/`, `Azure/`, `GCP/` — cloud provider content
- `Docker/`, `Kubernetes/`, `Helm/` — containers and orchestration
- `Terraform/`, `OpenTofu/`, `Ansible/` — infrastructure as code and config management
- `Git/`, `GitHub/`, `GitHub Actions/`, `GitLab/`, `GitLab CI/` — source control and CI
- `Prometheus/`, `graf/`, `grafc/`, `otel/`, `plm/`, `vlt/` — observability and secrets
- `ArgoCD/`, `FluxCD/` — GitOps
- `Trivy/` — security scanning
- `docs/` — cross-cutting docs
- `00_index/` — navigation
